# Design Tokens — Google Stitch MCP

Conform to Google Stitch MCP UI/UX patterns: clean surfaces, high-contrast text, generous touch targets, no clutter.

## 1. Color Palette
- **Background:** `#ffffff` (Clean white base)
- **Surface:** `#f8f9fa` (Light gray cards)
- **Primary:** `#1a73e8` (Google Blue action buttons)
- **Secondary:** `#ea4335` (Accent red for alerts)
- **Text Primary:** `#202124` (Near black)
- **Text Secondary:** `#5f6368` (Gray)
- **Border:** `#dadce0` (Subtle dividers)
- **Flash Overlay:** `#ffffff` (Pure white 350ms flash)

## 2. Typography
- **Font Family:** 'Google Sans', system-ui, -apple-system, sans-serif
- **Headings:** 500–700 weight, 1.2 line-height
- **Body:** 400 weight, 1.5 line-height

## 3. Spacing & Touch Targets
- **Minimum Tap Height:** 72px primary buttons, 56px secondary
- **Border Radius:** 8px containers, 24px pills/badges
- **Padding:** 16px grid (8px, 16px, 24px, 32px)
- **Card Shadow:** `0 1px 2px 0 rgba(60,64,67,0.3), 0 1px 3px 1px rgba(60,64,67,0.15)`

## 4. Layout
- **Max Container Width:** 1200px centered
- **Screen Padding:** 24px horizontal on iPad
- **Card Gap:** 16px between elements
- **Template Preview:** 340×510px cards with 12px rounded corners
